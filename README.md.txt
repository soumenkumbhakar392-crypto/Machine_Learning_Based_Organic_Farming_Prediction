# Organic Farming Prediction

## Project Overview
This project predicts whether soil and weather conditions are suitable for organic farming using a Machine Learning model.

## Dataset
The dataset contains 500 synthetically generated records with these features:
- Soil_pH
- Temperature
- Rainfall
- Humidity
- Soil_Moisture
- Suitability (Target)

**Note:** This is a synthetic educational dataset generated using predefined rules. It is not real-world agricultural field data.

## Machine Learning
- Random Forest Classifier
- Train-Test Split
- Classification Report
- Confusion Matrix

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- ipywidgets

## How to Run
1. Install the required libraries.
2. Open `Organic_Farming_Prediction.ipynb` in Jupyter Notebook.
3. Run the notebook cells in order.
